# BTG Tech

BTG Tech is a technology mod for Minecraft on NeoForge by Betelgeuse Interactive: energy generation and storage, processing and automation machines, and advanced item and fluid storage. Space technology is planned after version 1.0.

## Status

Early development; there is no release yet. Progress is tracked in the [roadmap](docs/roadmap/roadmap.md).

## Requirements

| Component | Version |
|---|---|
| Minecraft | 26.1.2 |
| NeoForge | 26.1.2.116 or newer |

## Building from Source

Requires JDK 25; Gradle is provided by the wrapper. See [environment setup](docs/development/environment-setup.md) for details.

```powershell
.\gradlew.bat build
```

The mod jar is written to `build/libs/`.
