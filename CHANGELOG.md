All notable changes to BTG Tech are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow `<major>.<minor>.<patch>+mc<minecraft version>` as described in the [Git workflow](docs/development/git-workflow.md#3-versions-and-tags).

## [Unreleased]

### Added

- BTG Tech loads on Minecraft 26.1.2 with NeoForge and appears in the mod list.
- The build checks code formatting, architecture rules and translation completeness.
- Bug report form for GitHub issues.
- "BTG Tech" creative tab, with its title in all eight languages.
- Tin ore in the overworld (stone and deepslate) and the tin and bronze materials: raw tin, ingots, nuggets, dusts, plates and storage blocks, with crafting and smelting recipes.
- Basic machine casing and Basic circuit, the crafting components of the first machines.
- Batteries in four tiers: they store energy, show it in their screen, give a comparator signal by fill level and follow their redstone mode.
- Solid fuel generators in four tiers: they burn furnace fuels, the same energy per fuel on every tier, faster on higher tiers.
- Server config with the battery values.
